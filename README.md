# Jogo Acadêmico de Lógica e Estruturas de Dados 🎮

## Descrição
Jogo criado com fins acadêmicos, focado no **aprendizado de lógica de programação e estruturação de dados**.  
O jogador deve se movimentar e atirar em inimigos que aparecem aleatoriamente durante a gameplay, que tem duração de **5 minutos**.

---

## Objetivos do Projeto
- Praticar conceitos de **lógica de programação**.  
- Aplicar **estruturas de dados** na gestão de inimigos, itens e pontuação.  
- Desenvolver **pensamento algorítmico** e resolução de problemas em tempo real.  

---

## Funcionalidades
- Movimento do jogador em diferentes direções.  
- Sistema de tiro para eliminar inimigos.  
- Spawn aleatório de inimigos ao longo da gameplay.  
- Contador de tempo de 5 minutos.  
- Sistema de pontuação baseado nos inimigos derrotados.  

---

## Tecnologias Utilizadas
- Linguagem: **GML (GameMaker Language)**  
- Ferramenta de desenvolvimento: **GameMaker Studio 2/3**  
- Estruturas de dados aplicadas: `Listas`, `Filas`, `Vetores` *(dependendo da implementação)*  

---

## Como Jogar
1. Abra o projeto no **GameMaker Studio**.  
2. Execute o jogo clicando em **Run** ou usando o atalho correspondente.  
3. Use as teclas de movimento para controlar o personagem.  
4. Atire nos inimigos para acumular pontos.  
5. O jogo termina após 5 minutos e sua pontuação final será exibida.
